================================================================
sauce.ai/news — install on GoDaddy Web Hosting Plus (cPanel)
================================================================

This document covers the *first-time* setup on the GoDaddy host.
CI/CD already syncs this repo into the account root, so the code
is on disk at:

    /home/YOURACCOUNT/sauce.ai/news/

You only need to do the steps below once per environment. After
that, every git push refreshes the code automatically; you just
"Restart" the Python app to pick up changes (step 6 covers this).

Conventions:
  YOURACCOUNT           = your cPanel username
  YOURACCOUNT_news      = example MySQL DB / user (yours will differ)
  $ ...                 = command in cPanel Terminal


------------------------------------------------------------------
0. WHAT YOU NEED
------------------------------------------------------------------
  - cPanel access (you have this).
  - SSH/Terminal enabled. If your plan does not include Terminal,
    every command below also works from
    "Setup Python App" -> "Enter to the virtual environment".
  - An Anthropic API key (https://console.anthropic.com).
    Optional: without one the classifier degrades to rules-only.
    The site still works; political_lean/objectivity just fall
    back to source-level defaults.

  Verify CI/CD landed the code:
      $ ls /home/YOURACCOUNT/sauce.ai/news/passenger_wsgi.py
  If that file exists you're ready for step 1.


------------------------------------------------------------------
1. CREATE THE DATABASE
------------------------------------------------------------------
1a) cPanel -> "MySQL Databases".
1b) Create a database:                YOURACCOUNT_news
1c) Create a user with a strong pw:   YOURACCOUNT_newsuser
1d) Add the user to the database with ALL PRIVILEGES.

1e) cPanel -> "phpMyAdmin" -> select the new DB -> "Import" ->
    upload  news/seed/schema.sql  -> Go.

1f) Same again with  news/seed/feature_catalog.sql .


------------------------------------------------------------------
2. CREATE THE PYTHON APP
------------------------------------------------------------------
2a) cPanel -> "Setup Python App" -> "Create Application":
        Python version:        3.10 (or whichever 3.x is offered)
        Application root:      sauce.ai/news
        Application URL:       sauce.ai/news
        Application startup:   passenger_wsgi.py
        Application entry pt:  application
    Click "Create".

2b) On the app's page, click "Edit" and add environment variables:

        SECRET_KEY              <generate: `python -c "import secrets;print(secrets.token_hex(32))"`>
        DB_HOST                 localhost
        DB_PORT                 3306
        DB_USER                 YOURACCOUNT_newsuser
        DB_PASSWORD             <password from step 1c>
        DB_NAME                 YOURACCOUNT_news
        APPLICATION_ROOT        /news
        ANTHROPIC_API_KEY       <your key, or leave blank for rules-only mode>
        ANTHROPIC_MODEL         claude-haiku-4-5-20251001
        ADMIN_EMAIL             your-email@example.com

    Save.

    NOTE: Do NOT commit a .env file to the repo. cPanel env vars
    are the canonical place for secrets here; the app reads them
    via app/config.py.

2c) On the same page, copy the "Enter to the virtual environment"
    command (it looks like:
        source /home/YOURACCOUNT/virtualenv/sauce.ai/news/3.10/bin/activate \
        && cd /home/YOURACCOUNT/sauce.ai/news
    ). Paste it into Terminal, then:

        $ pip install -r requirements.txt

    If `feedparser` -> `sgmllib3k` fails to build, run:
        $ pip install --no-build-isolation feedparser
    first, then re-run pip install.


------------------------------------------------------------------
3. FIRST RUN
------------------------------------------------------------------
3a) Back on "Setup Python App", click "Restart".

3b) Visit  https://sauce.ai/news/auth/signup  and create your
    account using ADMIN_EMAIL from step 2b.

3c) In phpMyAdmin, run:
        UPDATE users SET is_admin = 1 WHERE email = 'your-email@example.com';

3d) Reload the site; you'll now see an "Admin" link in the nav.

3e) Go to  https://sauce.ai/news/admin/feeds  -> click
    "Import / refresh seed CSV". This loads ~135 seed sources.


------------------------------------------------------------------
4. CRON JOBS
------------------------------------------------------------------
cPanel -> "Cron Jobs". You need the path to the venv's python; copy
it from the "Setup Python App" page (under "Python executable").
Example:  /home/YOURACCOUNT/virtualenv/sauce.ai/news/3.10/bin/python

Add four cron jobs (replace PYTHON and HOME accordingly):

  # every 15 minutes: fetch RSS feeds
  */15 * * * *  cd /home/YOURACCOUNT/sauce.ai/news/jobs && PYTHON /home/YOURACCOUNT/sauce.ai/news/jobs/fetch_feeds.py >/dev/null 2>&1

  # every 5 minutes: classify pending articles (rules + LLM)
  */5  * * * *  cd /home/YOURACCOUNT/sauce.ai/news/jobs && PYTHON /home/YOURACCOUNT/sauce.ai/news/jobs/classify_pending.py >/dev/null 2>&1

  # every 30 minutes: poll Reddit + HN for popularity signals
  */30 * * * *  cd /home/YOURACCOUNT/sauce.ai/news/jobs && PYTHON /home/YOURACCOUNT/sauce.ai/news/jobs/popularity_poll.py >/dev/null 2>&1

  # nightly 3:30am UTC: prune old data, refresh journalist reputation
  30  3  * * *  cd /home/YOURACCOUNT/sauce.ai/news/jobs && PYTHON /home/YOURACCOUNT/sauce.ai/news/jobs/maintenance.py >/dev/null 2>&1

You can run each one manually first from Terminal to confirm it works:

  $ source /home/YOURACCOUNT/virtualenv/sauce.ai/news/3.10/bin/activate
  $ cd /home/YOURACCOUNT/sauce.ai/news/jobs
  $ python fetch_feeds.py
  $ python classify_pending.py


------------------------------------------------------------------
5. VERIFY
------------------------------------------------------------------
5a) Visit  https://sauce.ai/news/admin  -> the "Overview" shows
    feed counts and pipeline state. After one or two classify
    runs you should see classified > 0.

5b) Visit  https://sauce.ai/news/admin/tests  -> click "Run tests".
    The bundled pytest suite should pass green.

5c) Visit  https://sauce.ai/news  -> sign up a second test
    account -> pick a preset -> verify the feed loads with cards.

5d) Visit  https://sauce.ai/news/firehose  -> articles should
    appear in real time as classify_pending runs.


------------------------------------------------------------------
6. DEPLOYING UPDATES
------------------------------------------------------------------
Code updates land via CI/CD on every push to main. To pick them up:

  - If you changed Python code or templates only:
        cPanel -> "Setup Python App" -> "Restart"
    (or:  $ touch /home/YOURACCOUNT/sauce.ai/news/tmp/restart.txt )

  - If you changed requirements.txt:
        $ source /home/YOURACCOUNT/virtualenv/sauce.ai/news/3.10/bin/activate
        $ cd /home/YOURACCOUNT/sauce.ai/news
        $ pip install -r requirements.txt
    then restart the Python app.

  - If you changed seed/schema.sql:
        phpMyAdmin -> Import (or run ALTER TABLE manually). This
        is intentionally NOT automated; schema migrations on
        shared hosting deserve human eyes.


------------------------------------------------------------------
7. ONGOING OPERATIONS
------------------------------------------------------------------
Admin pages (require is_admin = 1):
  /admin              overview & pipeline / LLM spend
  /admin/feeds        per-source status; add/disable/delete feeds
  /admin/content      7-day breakdown by category / source, lean histogram
  /admin/users        list / promote / delete users
  /admin/traffic      signups, clicks, top articles
  /admin/features     edit feature catalog (controls UI of "Your Algo")
  /admin/logs         pipeline_log table tail
  /admin/tests        run pytest

Logs:
  cron jobs also write to /home/YOURACCOUNT/sauce.ai/news/logs/*.log
  and to the pipeline_log table (visible in /admin/logs).


------------------------------------------------------------------
8. TROUBLESHOOTING
------------------------------------------------------------------
- 500 errors on every request:
    Setup Python App -> "stderr.log". 95% of the time it's a
    missing env var or wrong DB credentials.

- Empty feed:
    Check /admin -> classified count. If 0, run classify_pending.py
    by hand from Terminal and read the output. If it says "LLM
    unavailable" that's fine — articles still classify with rules.

- feedparser sgmllib3k build error:
    pip install --no-build-isolation feedparser

- Articles never get popularity > 0:
    Normal — popularity_poll.py only matches URLs that appear on
    Reddit/HN. Typical match rates ~5-10% after a week.

- "Module not found: app":
    Make sure the Python App's "Application root" is exactly
    sauce.ai/news (not just sauce.ai). The app expects
    passenger_wsgi.py at the root of its own directory.

- Changes from a fresh git push don't show up:
    Restart the Python App. CI/CD writes files but Passenger keeps
    the old import cached until restart.


------------------------------------------------------------------
9. KNOWN v1 LIMITATIONS (will be addressed in v2)
------------------------------------------------------------------
- Python user algorithms: UI-only in v1. The "Code" tab shows the
  generated Python equivalent but does not execute user-supplied
  code. Sandboxed execution is intentionally deferred.
- No CSRF tokens beyond same-site cookies, no email verification,
  no rate limiting on auth endpoints. Treat the prototype as
  password-protected by obscurity until v2.
- Articles store summary + link only (no full-text extraction).
- Popularity is from Reddit + HN externally; internal click signal
  is recorded but not yet folded into the popularity score.

You're done. Visit  https://sauce.ai/news .
