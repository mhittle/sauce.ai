  1. Search + one-hop citation snowball; model-suggested papers kept only if they resolve in PubMed.
  2. Screen abstracts; read included papers (open-access full text when available).
  3. Extract algorithms and accuracy figures, each backed by a verbatim quote.
  4. Pool across validations, grade the evidence (QUADAS-2 / GRADE-style), rank.
