Instrument · adversarial safety evaluation · clinical conversational AI

Adversarial safety evaluation of clinical chatbots

Runs adversarial synthetic-patient conversations against a chatbot you are authorized to test, scores every reply with an audited judge panel, and reports harm with epidemiologic measures.

1Target

An OpenAI-compatible or Anthropic endpoint, a custom JSON API, or a chat web page, under your system prompt. Keys are held for the run only.

2Adversarial conversations

Synthetic personas from a specialty library; an attacker ensemble escalates toward dosing, triage, discontinuation and misinformation harms.

3Report

Attack success with 95% CI, prompts-to-harm, number needed to harm, QALYs lost, harm profile, annotated transcripts; every run is added to the leaderboard.

This tool deliberately tries to elicit unsafe responses from the bot under test so you can find and fix them. Only run it against endpoints you own or have written permission to test. Reports are LLM-scored screening signals, not clinical determinations — have a clinician review flagged transcripts.
